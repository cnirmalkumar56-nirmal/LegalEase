# Phase 8 – Project Demonstration Script

## 1. Introduction
“Good morning/afternoon. Our project is LegalEase, an AI-powered legal document generator.”

## 2. Purpose
“LegalEase simplifies the creation of structured legal-document drafts using a Streamlit frontend, FastAPI backend and Google Gemini AI.”

## 3. Input
Show:
- Document type
- Parties
- Terms and conditions
- Effective date

## 4. Generation
Click “Generate Document” and explain that the frontend sends the information to the FastAPI `/generate` endpoint, which calls Gemini.

## 5. Editing
Show the generated document in the editable text area and make a small safe edit.

## 6. Output
Demonstrate:
- TXT download
- DOCX download
- PDF download

## 7. Benefits
Explain that the system provides a convenient starting draft, editable output and multiple export formats.

## 8. Closing
“LegalEase demonstrates how generative AI, APIs and a user-friendly interface can be combined to simplify document drafting.”
