# Phase 1 – Brainstorming & Ideation

## Project Title
LegalEase – AI-Powered Legal Document Generator

## Problem Statement
Creating structured legal-document drafts can be difficult for users without legal-document experience.

## Proposed Solution
LegalEase provides a simple interface where users enter the document type, parties, terms and effective date. The system uses Gemini to generate a structured draft and provides editing and export options.

## Main Objectives
- Simplify document drafting.
- Provide editable generated content.
- Support TXT, DOCX and PDF exports.
- Provide a simple Streamlit interface.
- Connect a FastAPI backend with Gemini AI.

## Target Users
Entrepreneurs, professionals, freelancers, landlords and individuals who need a starting draft.

## Scope
The project focuses on document drafting and formatting. It does not replace professional legal advice.
